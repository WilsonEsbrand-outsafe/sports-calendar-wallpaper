# 스포츠 달력 바탕화면

Wallpaper Engine 웹 월페이퍼. 평소에는 응원 팀 홈구장 전경만 보이고, **오른쪽 아래 📅 버튼(또는 빈 곳 더블클릭)으로 켜면** 달력 + KBO/EPL 경기 일정 + 할 일 + 일정 + 현재 재생 중인 음악이 나온다.

```
바탕화면 (기본)
└── 경기장 전경 사진 · 오른쪽 아래 📅 버튼

달력을 켰을 때
├── 왼쪽    월/팀 · 오늘 날짜와 시계 · 오늘 경기 · 할 일 · 다가오는 일정
├── 가운데  달력 (경기 결과/시각, 개인 일정, 공휴일)
└── 오른쪽  이번 달 성적 · 다음 경기 카운트다운 · 리그 전환 · 재생 중인 음악
```

---

## 1. 처음 설치

### KBO 경기 데이터 서버

경기 일정은 별도 로컬 서버(`C:\Users\user\kbo-scraper`)에서 온다. 이게 안 떠 있으면 달력에 경기가 안 나온다.

부팅할 때 자동으로 뜬다. 등록 위치는 시작프로그램 폴더:

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\start-kbo.vbs
```

지금 바로 띄우려면 그 파일을 더블클릭하면 된다. 잘 떴는지는 브라우저에서 확인:

```
http://localhost:8080/api/game-schedule/DOOSAN/2026-09-03
```

> **주의** — `start-kbo.vbs` 는 `kbo-scraper` 폴더와 시작프로그램 폴더 **두 군데에 사본이 있다.**
> 한쪽만 고치면 부팅 때는 옛날 것이 뜬다. 고쳤으면 반드시 복사해서 맞춰줄 것.

### 월페이퍼 적용

저장소에는 `project.json` 이 없다(개인 토큰이 들어가서). `project.example.json` 을 `project.json` 으로 복사해서 쓴다.

Wallpaper Engine → 내 작품에서 "스포츠 달력" 선택 → 적용.

## 2. WE 속성창 설정

월페이퍼를 고른 뒤 왼쪽 속성 목록에서 설정한다.

| 항목 | 설명 |
|---|---|
| KBO 팀 선택 | 응원 팀. 달력·성적·카운트다운·배경 사진이 이 팀 기준 |
| KBO 서버 주소 | 기본 `http://localhost:8080`. 보통 건드릴 일 없음 |
| EPL 팀 이름 | 영문 팀명 (예: `Manchester City`) |
| football-data.org API Key | EPL을 쓸 때만 필요. [무료 발급](https://www.football-data.org/client/register) |
| 표시할 리그 | KBO / EPL |
| 배경 사진 경로 | 비워두면 응원 팀 홈구장 사진. 아래 4번 참고 |
| 할 일 / 개인 일정 | 예전 방식. 지금은 바탕화면에서 바로 입력하는 게 편하다 (3번) |
| Google Client ID / Secret / Refresh Token | 구글 캘린더·할 일 연동 (5번) |

## 3. 할 일 / 일정 다루기

### 글자 입력은 바탕화면에서 안 된다

Windows 는 바탕화면 배경 창에 **키보드 포커스를 주지 않는다.** 마우스 클릭은 Wallpaper Engine 이 따로 전달해 주지만 키 입력은 전달되지 않는다. 그래서 월페이퍼 위의 입력칸은 **WE 편집기 미리보기에서만** 타이핑이 된다.

대신 **섹션 제목 옆 버튼을 누르면 기본 브라우저로 바로 열린다.**

| 버튼 | 열리는 곳 |
|---|---|
| **Tasks ↗** | tasks.google.com — 여기 적으면 "할 일" 칸에 뜬다 |
| **Calendar ↗** | calendar.google.com — 여기 적으면 "다가오는 일정"과 달력에 뜬다 |

월페이퍼 위의 입력칸은 없앴다. 쓸 수 없는 칸을 띄워두면 거짓말이 되기 때문이다.

**링크가 열리는 방식** — WE 의 CEF 는 `target="_blank"` 팝업을 열어주지 않아서 페이지 안에서는 외부 링크를 띄울 수 없다. 그래서 KBO 서버의 `/api/open/{키}` 에 요청을 보내고, **서버가 기본 브라우저를 대신 연다.** (KBO 일정이 뜨는 것과 같은, 이미 동작이 확인된 통로다)

즉 **이 버튼들은 KBO 서버가 떠 있어야 동작한다.** 서버가 죽어 있으면 옛 방식(팝업)이라도 시도하지만 WE 안에서는 거의 열리지 않는다.

임의의 URL 이 아니라 미리 정해둔 키(`tasks` `calendar` `kbo` `epl`)만 받는다. 로컬에 열린 엔드포인트라 URL 을 그대로 받으면 아무 웹페이지나 이 주소를 호출해 원하는 창을 띄울 수 있기 때문이다. 서버도 `127.0.0.1` 로만 바인딩된다.

**글자를 넣는 곳**

| 방법 | 어디서 | 좋은 점 |
|---|---|---|
| 구글 Tasks | **Tasks ↗** 버튼 · 폰 | 클릭 한 번. 폰에서도 추가 (5번 설정 필요) |
| 구글 캘린더 | **Calendar ↗** 버튼 · 폰 | 클릭 한 번. 시간까지 표시된다 |
| WE 속성창 `할 일` / `개인 일정` | WE 창 | 구글 설정이 아예 필요 없다 |

속성창 형식:
- 할 일 — `장보기 | v 운동 | 우유 사기` (`v ` 를 앞에 붙이면 완료)
- 개인 일정 — `09-15:치과 | 12-25:크리스마스` (연도 없이 `MM-DD`, 매년 반복에 적합)

### 마우스로 되는 것

- **네모 클릭 → 완료 / 완료 취소.** 속성창 항목이든 구글 Tasks 항목이든 전부 체크된다.
  (원본은 못 고치므로 완료 여부만 이 PC 에 따로 저장된다)
- **삭제는 원본에서.** 바탕화면에서는 지울 수 없으니 구글 Tasks / 캘린더 / WE 속성창에서 지운다.
- 개인 일정은 달력 칸에도 파란 칩으로 표시된다.

**그 외**
- **📅 (오른쪽 아래)** — 달력 켜기 / 끄기. 월페이퍼를 처음 띄우면 꺼져 있다
- **KBO / EPL 버튼** — 리그 전환
- **‹ ›** — 달력 월 이동
- **빈 곳 더블클릭** — 📅 버튼과 같다 (버튼·항목 위에서는 동작 안 함)

## 4. 배경 사진 (경기장 전경)

`assets/stadium/` 에 홈구장 이름으로 사진을 넣으면 응원 팀을 바꿀 때 배경도 그 팀 홈구장으로 바뀐다.

| 파일 | 팀 |
|---|---|
| `jamsil.jpg` | LG · 두산 (잠실) |
| `munhak.jpg` | SSG (인천 문학) |
| `suwon.jpg` | KT (수원) |
| `changwon.jpg` | NC (창원) |
| `daegu.jpg` | 삼성 (대구) |
| `sajik.jpg` | 롯데 (사직) |
| `daejeon.jpg` | 한화 (대전) |
| `gwangju.jpg` | KIA (광주) |
| `gocheok.jpg` | 키움 (고척) |
| `default.jpg` | EPL 모드, 또는 팀 사진이 없을 때 |

사진은 저장소에 없다(저작권). 직접 찍었거나 사용 허락된 사진을 넣을 것. 화면 비율(16:9)에 맞춰 가운데 기준으로 잘려 꽉 차게 보인다.

속성창의 "배경 사진 경로"에 직접 적으면 팀과 무관하게 그 파일을 쓴다.
속성창 경로 → 팀 홈구장 → `default.jpg` 순서로 열리는 첫 사진을 쓰고, 하나도 없으면 예전의 베이지색 배경이 나온다.

달력을 켜면 글자가 읽히도록 사진 위에 밝은 막이 한 겹 덮인다. 진하기는 `index.html` 의 `.bg-photo::after` 투명도로 조절한다.

## 5. 구글 캘린더 / 할 일 연동

액세스 토큰은 1시간이면 만료되므로 **Refresh Token 방식**만 쓴다. 아래 3개를 속성창에 넣으면 이후로는 알아서 갱신한다.

1. [Google Cloud Console](https://console.cloud.google.com/) → 프로젝트 생성
2. **API 및 서비스 → 라이브러리** 에서 `Google Calendar API`, `Google Tasks API` 사용 설정
3. **사용자 인증 정보 → OAuth 클라이언트 ID → 데스크톱 앱** 생성
   → **Client ID** / **Client Secret** 획득
4. [OAuth Playground](https://developers.google.com/oauthplayground/) 에서 Refresh Token 발급
   - 우측 위 톱니 → *Use your own OAuth credentials* 체크 → 위 ID/Secret 입력
   - 범위에 아래 두 개 입력 후 승인
     ```
     https://www.googleapis.com/auth/calendar.readonly
     https://www.googleapis.com/auth/tasks.readonly
     ```
   - *Exchange authorization code for tokens* → **Refresh token** 복사
5. 속성창의 Client ID / Client Secret / Refresh Token 세 칸에 붙여넣기

연동이 안 되면 "다가오는 일정" 자리에 실패 이유가 그대로 표시된다.

## 6. 음악

Wallpaper Engine이 Windows 미디어 세션을 그대로 넘겨준다. **토큰이나 로그인이 필요 없고**, Spotify·유튜브·브라우저·로컬 플레이어 무엇이든 재생 중이면 제목·아티스트·앨범아트·진행 시간이 뜬다.

WE 설정 → **일반 → 미디어 통합**이 켜져 있어야 한다. 꺼져 있으면 카드에 안내 문구가 나온다.

재생/다음곡 버튼은 없다. WE는 정보를 읽어오기만 하고 제어 API는 주지 않는다.

## 7. 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 달력에 경기가 없다 | **"오늘 경기" 칸을 클릭하면 즉시 다시 불러온다.** 실패하면 그 자리에 이유가 표시된다. 부팅 직후엔 서버(Spring, 약 30초)가 월페이퍼보다 늦게 떠서 비어 보일 수 있고, 데이터가 들어올 때까지 20초마다 최대 5분간 자동 재시도한다 |
| **Tasks ↗ / Calendar ↗ 를 눌러도 안 열린다** | KBO 서버가 떠 있어야 한다 (1번). `curl http://localhost:8080/api/open/tasks` 로 직접 확인할 수 있다 |
| **클릭이 안 먹는다** | WE 설정에서 **"다른 프로그램 실행 중 일시 정지"** 로 월페이퍼가 멈춰 있으면 클릭도 안 먹는다. 창을 최소화하고 바탕화면이 보이는 상태에서 눌러볼 것 |
| 배경 사진이 안 나온다 | `assets/stadium/` 의 파일 이름이 4번 표와 같은지 (`.jpg`, 소문자) |
| 달력이 안 보인다 | 정상이다. 오른쪽 아래 📅 버튼이나 빈 곳 더블클릭으로 켠다 |
| 음악이 안 뜬다 | WE 설정 → 일반 → 미디어 통합 (6번) |
| 일정/할 일이 안 뜬다 | 패널에 표시되는 오류 메시지 확인 (5번) |
| 월페이퍼에 타이핑이 안 된다 | 정상이다. 위 3번 참고 |
| 글자가 너무 크거나 작다 | `index.html` 의 `DESIGN_WIDTH`(기본 1536) 를 조절. 화면 폭에 비례해 전체가 확대된다 |

## 8. 코드를 고친 뒤

- **월페이퍼(`index.html`)** — WE에서 월페이퍼를 다시 적용하면 반영된다.
- **KBO 서버(Kotlin)** — jar를 다시 만들어야 반영된다. 실행 중인 서버를 먼저 끄고:
  ```
  cd C:\Users\user\kbo-scraper
  gradlew.bat bootJar
  ```

---

## 9. 워크샵에 올릴 때

`project.json` 에 **Google Refresh Token 과 Client ID 가 평문으로 들어 있다.** 업로드하면 그대로 공개되니 올리기 전에 반드시 비울 것.
